# 📖 Инструкция пользователя: Etix Checker 2026 — AdsPower CDP Edition

Добро пожаловать в **Etix Checker 2026**! Это специализированное высокопроизводительное приложение для автоматизированной проверки наличия билетов, мониторинга инвентаря и распределенного резервирования корзин на платформе **Etix.com** с использованием браузерных профилей **AdsPower** по протоколу Chrome DevTools Protocol (CDP).

---

## ⚡ Быстрый старт (Установка в 1 клик)

Для установки и первого запуска вам достаточно запустить один файл:
1. Запустите **`setup_installer.bat`** двойным кликом.
2. Установщик выполнит все действия полностью автоматически:
   - Проверит наличие Python (при необходимости скачает и установит Python 3.11).
   - Создаст изолированное виртуальное окружение `venv`.
   - Установит все библиотеки и внутренний браузер Playwright Chromium.
   - Создаст файл конфигурации `.env`.
   - Проверит подключение к AdsPower Local API (порт 50325).
   - Создаст удобный ярлык на рабочем столе: **«Etix Checker 2026»**.
3. После завершения установки приложение готово к работе!

---

## ⚙️ Настройка AdsPower

Перед запуском проверки убедитесь, что ваш браузер **AdsPower** настроен:

1. **Запустите приложение AdsPower** на компьютере.
2. Перейдите в **Настройки** AdsPower $\rightarrow$ **Local API**:
   - Убедитесь, что Local API включен.
   - Порт по умолчанию: **`50325`** (URL: `http://127.0.0.1:50325`).
3. В AdsPower создайте группу профилей с названием:
   ```text
   Inventory Etix (DO NOT TOUCH)
   ```
4. Поместите в эту группу ваши профили с настроенными качественными резидентскими или мобильными прокси (рекомендуется от 12 до 20+ профилей).
5. При запуске чекер автоматически разделит профили на **активные** (по умолчанию 12 воркеров) и **резервные** (для мгновенной горячей замены в случае сбоя прокси).

## 📋 Как заполнять файл событий `data/shows.csv`

Файл **`data/shows.csv`** содержит список мероприятий, которые необходимо проверить. Вы можете открыть и отредактировать его прямо из интерфейса программы, нажав кнопку **`📄 shows.csv`**, или открыть в Excel / Блокноте.

### Структура таблицы:
```csv
name,url,target_total,max_per_order,ticket_index
```

### Описание каждого столбца:
| Столбец | Что означает | Пример | Пояснение |
| :--- | :--- | :--- | :--- |
| **`name`** | Название события | `Gasolina Party` | Любое понятное вам имя (без запятых). |
| **`url`** | Ссылка на мероприятие | `https://www.etix.com/ticket/p/...` | Полная ссылка на страницу покупки билетов Etix. |
| **`target_total`** | Общая цель билетов | `24` | Сколько всего билетов нужно суммарно набрать по всем профилям. |
| **`max_per_order`** | Лимит на один заказ | `6` | Сколько билетов должен взять один профиль за один раз. |
| **`ticket_index`** | Номер типа билета | `2` | **1** = первый тип билета сверху, **2** = второй тип билета сверху, и т.д. |

### Пример готового файла `shows.csv`:
```csv
name,url,target_total,max_per_order,ticket_index
NateSmith,https://www.etix.com/ticket/p/35196855/nate-smith-palmer-alaska-state-fair,12,4,2
Gasolina Party,https://www.etix.com/ticket/p/87677793/gasolina-party-providence-the-strand-theatre?partner_id=100,24,6,2
```

> [!TIP]
> **Как работает распределение корзин:**
> Если для `Gasolina Party` указана цель `target_total = 24`, а лимит `max_per_order = 6`, чекер автоматически задействует **4 профиля AdsPower** ($24 \div 6 = 4$), каждый из которых одновременно положит в корзину по 6 билетов.

## 🖥️ Работа с Графическим интерфейсом (GUI)

Запустить интерфейс можно через ярлык на рабочем столе, через **`run_gui.bat`** или файл **`run_gui.vbs`** (для запуска без лишнего черного окна консоли).

### Главные элементы управления:
1. **Индикатор подключения AdsPower (вверху справа):**
   - 🟢 **Зеленый кружок:** AdsPower подключен, показано число активных и резервных профилей.
   - 🔴 **Красный кружок:** AdsPower закрыт или Local API выключен.
2. **Панель кнопок:**
   - **`▶ Запустить проверку`** — запускает сквозной процесс проверки и резервирования билетов.
   - **`💾 Бэкап профилей`** — сохраняет резервную копию метаданных всех профилей AdsPower в папку `data/adspower_backup/`.
   - **`📄 shows.csv`** — мгновенно открывает список событий для редактирования.
   - **`📊 report.csv`** — открывает итоговую таблицу с результатами последней проверки.
   - **`📁 Логи`** — открывает папку с подробными техническими логами.
3. **Панель мониторинга (Карточки событий):**
   - Наглядно показывает каждое событие из `shows.csv`.
   - Отображает живой **прогресс-бар**, количество набранных билетов (`0 / 24` $\rightarrow$ `24 / 24`) и цветной бейдж статуса.
4. **Вкладка «📜 Журнал событий (Лог)»:**
   - Показывает подробные действия программы в реальном времени (открытие страниц, клики, обход проверок, освобождение корзин).

## 📊 Результаты проверки (`report.csv`)

После завершения проверки в корневой папке создается или обновляется отчет **`report.csv`**.

### Расшифровка статусов:
| Статус | Цвет | Что означает |
| :--- | :--- | :--- |
| **`OK`** | 🟢 Зеленый | Мероприятие полностью доступно. Цель по билетам набрана на 100% во всех профилях. |
| **`ЧАСТИЧНО`** | 🟡 Желтый | Удалось набрать только часть билетов (например, в наличии было меньше, чем цель `target_total`). В отчете указано точное набранное число. |
| **`SOLD OUT`** | 🔴 Красный | Все билеты на мероприятие полностью раскуплены. |
| **`SALES ENDED`** | ⚪ Серый | Продажи на данное событие официально завершены организатором. |
| **`BLOCKED`** | 🟣 Фиолетовый | Доступ временно ограничен защитой DataDome (скрипт автоматически делает попытки ротации прокси). |
| **`FAILED`** | 🔴 Темно-красный | Ошибка загрузки страницы или сбой сети на всех доступных прокси. |

## 🛡️ Встроенные интеллектуальные механизмы

* **Авто-очистка корзин:** После проверки инвентаря чекер выдерживает заданную паузу удержания (по умолчанию 4 сек) и автоматически нажимает **`Clear Shopping Cart`**, возвращая билеты обратно в продажу.
* **Авто-корректировка лимита площадки:** Если вы указали лимит 6, а сайт строго разрешает максимум 4 (`over the per order limit of 4`), скрипт автоматически определит реальный лимит площадки, перевыберет 4 билета и успешно сформирует заказ.
* **Фильтрация цен «Best Available»:** Чекер безошибочно различает выпадающие списки количества и меню выбора ценовых тарифов на любых страницах Etix (включая Material-UI и классический HTML).
* **Горячая замена прокси:** Если у одного из активных профилей произошел сетевой сбой, чекер автоматически выведет его из строя и подставит свежий профиль из резерва.

## ❓ Часто задаваемые вопросы (FAQ)

**В: Индикатор AdsPower горит красным «Офлайн». Что делать?**
> **О:** Убедитесь, что приложение AdsPower запущено на вашем компьютере, и в его настройках активирован Local API на порту 50325.

**В: Как запустить чекер в консольном режиме без графического интерфейса?**
> **О:** Запустите файл **`run.bat`** (или выполните команду `venv\Scripts\python.exe cli.py`).

**В: Можно ли прервать проверку и продолжить позже?**
> **О:** Да, чекер автоматически сохраняет контрольные точки (`checkpoint.json`). При повторном запуске он продолжит работу с не проверенных событий.
