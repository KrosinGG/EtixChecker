# 🎟️ Etix Checker 2026 — AdsPower CDP Edition

Высокопроизводительный асинхронный чекер доступности и инвентаря билетов на платформе **Etix**, работающий на базе антидетект-браузеров **AdsPower Local API** через протокол **Playwright CDP (Chrome DevTools Protocol)**.

---

## 🌟 Ключевые возможности

* 🚀 **AdsPower CDP Engine:** Управление пулом изолированных браузерных профилей SunBrowser с уникальными цифровыми отпечатками железа и выделенными резидентскими/мобильными прокси.
* ⚡ **Автоматический установщик (One-Click Installer):** Развертывание всего проекта, Python 3.11, виртуального окружения `venv`, Playwright Chromium и ярлыка на рабочем столе за один клик через `setup_installer.bat`.
* 🎨 **Современный Dark Dashboard GUI:** Стильный темный интерфейс в эстетике Slate-Navy & Indigo с живыми метриками, динамическими карточками событий, прогресс-барами и журналом событий.
* 🧩 **Интеллектуальная фильтрация селекторов:** Точное определение селекторов количества билетов (как в Material-UI v5 `[role="combobox"]`, так и в классических HTML `<select>`) с автоматическим исключением выпадающих списков цен и тарифов (*Best Available* / *Лучшие из доступных*).
* 🛡️ **Авто-корректировка лимита площадки:** При возникновении ограничений площадки (*Sorry, over the per order limit of X*) чекер автоматически определяет реальный лимит площадки, перевыбирает допустимое число билетов и формирует заказ.
* 🎲 **Динамическое масштабирование и рандомизация пула:** Чекер вычисляет точное число необходимых профилей ($\lceil\text{target\_total} / \text{max\_per\_order}\rceil$) и выбирает их случайным образом из активного пула для равномерного распределения нагрузки по прокси.
* ⏳ **Конвейер случайных задержек (Staggered Human-Paced Pipeline):** Навигация, выбор количества, добавление в корзину и очистка корзины выполняются с настраиваемыми человеческими сдвигами во времени (джиттером), имитируя одновременный, но естественный поток пользователей (~45 секунд на шоу при 12 профилях).
* 🛡️ **3-этапная система обхода DataDome и мертвых прокси:**
  1. **Плавный Drag & Drop:** Автоматический сдвиг слайдера DataDome по кривой Безье с микроколебаниями мыши.
  2. **Сброс куки сессии (Soft Reset):** Очистка куки через CDP и открытие ссылки в чистой вкладке.
  3. **Горячая замена (Hot-Swap):** Мгновенная замена упавшего профиля на чистый из резервного пула с автоматическим назначением проверенного прокси через AdsPower API.
* 🛒 **Мгновенная очистка корзин (`Clear Shopping Cart`):** Автоматическое освобождение зарезервированного инвентаря в один клик с подтверждением диалоговых окон.
* 💾 **Чекпоинты и отказоустойчивость:** Автоматическое сохранение состояния проверки в реальном времени. В случае перезапуска проверка продолжается с прерванного места.
* 🔄 **Обновление в 1 клик (1-Click Updater):** Встроенная в GUI кнопка «Проверить обновления» с автоматической загрузкой и накатыванием свежих версий с GitHub без риска затирания пользовательских файлов `.env` и `shows.csv`.
* 🛡️ **Строгий барьер готовности воркеров (Readiness Barrier):** Гарантия того, что 100% задействованных профилей успешно перешли на целевой URL события, преодолели капчу/блокировки и готовы к одновременному набору корзин.
* 📖 **Подробная инструкция для пользователей:** Файл [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md) с пошаговыми инструкциями для конечных пользователей.

## ⚡ Быстрый старт (One-Click)

### 1. Автоматическая установка
Просто запустите файл **`setup_installer.bat`** двойным кликом. Он выполнит все настройки:
* Проверит/установит Python 3.11.
* Создаст изолированное окружение `venv` и установит все зависимости.
* Установит браузер Playwright Chromium в локальный кэш `ms-playwright/`.
* Создаст файл конфигурации `.env`.
* Создаст ярлык **«Etix Checker 2026»** на рабочем столе.

### 2. Подготовка AdsPower
1. Запустите десктопный клиент **AdsPower**.
2. Включите **Local API** на порту **50325** (по умолчанию `http://127.0.0.1:50325`).
3. Создайте группу с названием:
   ```text
   Inventory Etix (DO NOT TOUCH)
   ```
4. Добавьте в эту группу ваши браузерные профили с прокси (рекомендуется от 12 шт.).

### 3. Заполнение `data/shows.csv`
Укажите ссылки на события в файле `data/shows.csv`:
```csv
name,url,target_total,max_per_order,ticket_index
NateSmith,https://www.etix.com/ticket/p/35196855/nate-smith-palmer-alaska-state-fair,12,4,2
Gasolina Party,https://www.etix.com/ticket/p/87677793/gasolina-party-providence-the-strand-theatre?partner_id=100,24,6,2
```
* **`name`**: Название события.
* **`url`**: Ссылка на страницу покупки билетов Etix.
* **`target_total`**: Общая цель по билетам (суммарно по всем профилям).
* **`max_per_order`**: Лимит на один заказ/профиль (например, 4 или 6).
* **`ticket_index`**: Номер типа билета (1-based: `1` — первый сверху, `2` — второй сверху).

### 4. Запуск проверки
* Через ярлык на рабочем столе **«Etix Checker 2026»**.
* Либо через файл **`run_gui.bat`** (или `run_gui.vbs`).
* Либо в консольном режиме через **`run.bat`**.

## 📊 Результаты проверки (`report.csv`)

По завершении проверки создается итоговый отчет `report.csv`:
```csv
name,status,target,reserved,available_approx,details,notes
Gasolina Party,OK,24,24,24,Успешно зарезервировано 24/24,
```

**Статусы событий:**
* 🟢 **`OK`** — Целевое количество билетов полностью набрано во всех корзинах.
* 🟡 **`ЧАСТИЧНО`** — Набрана только часть билетов (например, 8/12 из-за нехватки билетов на сайте).
* 🔴 **`SOLD OUT`** — Все билеты на мероприятие раскуплены.
* ⚪ **`SALES ENDED`** — Продажи официально завершены.
* 🟣 **`BLOCKED`** — Блокировка DataDome (после всех попыток восстановления и ротации).
* 🔴 **`FAILED`** — Ошибка загрузки страницы или сбой всех прокси.
