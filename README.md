# 🎟️ Etix Checker 2026 — AdsPower CDP Edition

Высокопроизводительный асинхронный чекер доступности и инвентаря билетов на платформе **Etix**, работающий на базе антидетект-браузеров **AdsPower Local API** через протокол **Playwright CDP (Chrome DevTools Protocol)**.

---

## 🌟 Ключевые возможности

* 🚀 **AdsPower CDP Engine:** Управление пулом изолированных браузерных профилей SunBrowser с уникальными цифровыми отпечатками железа и выделенными резидентскими/мобильными прокси.
* 🧩 **Поддержка Material-UI (React) и Classic форм:** Автоматическое определение как современных выпадающих списков Material-UI (`[role="combobox"]`, `.MuiSelect-select`), так и классических HTML-селекторов `<select>`.
* 🎲 **Динамическое масштабирование и рандомизация пула:** Чекер вычисляет точное число необходимых профилей ($\lceil\text{target\_total} / \text{max\_per\_order}\rceil$) и выбирает их случайным образом из активного пула для равномерного распределения нагрузки по прокси.
* ⏳ **Конвейер случайных задержек (Staggered Human-Paced Pipeline):** Навигация, выбор количества, добавление в корзину и очистка корзины выполняются с настраиваемыми человеческими сдвигами во времени (джиттером), имитируя одновременный, но естественный поток пользователей (~45 секунд на шоу при 12 профилях).
* 🛡️ **3-этапная система обхода DataDome и мертвых прокси:**
  1. **Плавный Drag & Drop:** Автоматический сдвиг слайдера DataDome по кривой Безье с микроколебаниями мыши.
  2. **Сброс куки сессии (Soft Reset):** Очистка куки через CDP и открытие ссылки в чистой вкладке.
  3. **Горячая замена (Hot-Swap):** Мгновенная замена упавшего профиля на чистый из резервного пула с автоматическим назначением проверенного прокси через AdsPower API.
* 🛒 **Мгновенная очистка корзин (`Clear Shopping Cart`):** Автоматическое освобождение зарезервированного инвентаря в один клик с подтверждением диалоговых окон.
* 🌐 **Синхронизация рабочих прокси (`good_proxies.txt`):** Возможность синхронизации проверенных прокси между всеми пользователями через GitHub Raw / Secret Gist без необходимости в выделенном сервере.
* 💾 **Чекпоинты и отказоустойчивость:** Автоматическое сохранение состояния проверки в реальном времени. В случае перезапуска проверка продолжается с прерванного места.
* 🖥️ **Два режима работы:** Современный графический интерфейс (**CustomTkinter GUI**) и интерактивная консольная панель (**Rich CLI**).

## 🚀 Быстрый старт

### 1. Требования
* **ОС:** Windows 10 / 11.
* **Python:** 3.10 – 3.14 (устанавливать в виртуальное окружение `venv`).
* **AdsPower:** Установленный десктопный клиент AdsPower с включенным **Local API** (по умолчанию порт `50325`).
* **Профили AdsPower:** Группа с названием `Inventory Etix (DO NOT TOUCH)` с загруженными профилями SunBrowser.

### 2. Установка зависимостей
Активируйте виртуальное окружение и установите библиотеки:
```powershell
.\venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

### 3. Настройка входных данных (`data/shows.csv`)
Заполните список целевых событий в файле `data/shows.csv`:
```csv
name,url,target_total,max_per_order,ticket_index
Nate Smith,https://www.etix.com/ticket/p/35196855/nate-smith-palmer-alaska-state-fair,12,4,2
```
* `name`: Название события.
* `url`: Прямая ссылка на страницу покупки Etix.
* `target_total`: Общее целевое количество билетов для резервирования.
* `max_per_order`: Лимит билетов на один заказ/профиль.
* `ticket_index`: Номер типа билета на странице (1-based: `1` — первый тип, `2` — второй тип и т.д.).

### 4. Запуск

#### Вариант А: Графический интерфейс (GUI)
Дважды кликните по **`run_gui.bat`** или выполните:
```powershell
.\venv\Scripts\python.exe gui_app.py
```

#### Вариант Б: Консольный интерфейс (CLI)
Дважды кликните по **`run.bat`** или выполните:
```powershell
.\venv\Scripts\python.exe cli.py
```

## ⚙️ Конфигурация и задержки (`.env` / `settings.py`)

Вы можете создать файл `.env` на основе `.env.example` для переопределения параметров:

```env
# AdsPower Settings
ADSPOWER_API_URL=http://127.0.0.1:50325
ADSPOWER_GROUP_NAME=Inventory Etix (DO NOT TOUCH)
ADSPOWER_ACTIVE_PROFILES_COUNT=12

# Remote Good Proxies Sync URL (GitHub Raw или Secret Gist)
GOOD_PROXIES_SYNC_URL=https://raw.githubusercontent.com/.../good_proxies.txt

# Navigation & Delays (диапазоны в миллисекундах)
ETIX_NAV_TIMEOUT=18000
ETIX_BATCH_NAV_DELAY_MS=600-1100
ETIX_AFTER_CLICK_SLEEP_MS=500-900
ETIX_ADD_SEQUENTIAL_DELAY_MS=1000-1800
ETIX_DELAY_BEFORE_CLEAR_CARTS_S=4.0
ETIX_CLEAR_CART_STAGGER_MS=600-1000
```

### 🛡️ Безопасные минимальные пороги (`MIN_SAFE_DELAYS`)
Для защиты от банов и гарантированной стабильности DOM зафиксированы жесткие нижние границы:
* Сдвиг открытия URL (`batch_nav_delay_ms`): **не менее `270 мс`**.
* Пауза после выбора dropdown (`after_click_sleep_ms`): **не менее `420 мс`** (для синхронизации React/MUI).
* Сдвиг клика «Add Tickets» (`add_sequential_delay_ms`): **не менее `520 мс`**.
* Ожидание ответа корзины (`post_add_wait_ms`): **не менее `1520 мс`**.
* Удержание билетов перед очисткой (`delay_before_clear_carts_s`): **не менее `2.2 сек`**.
* Сдвиг очистки корзин (`clear_cart_stagger_ms`): **не менее `320 мс`**.

## 📊 Результаты проверки (`report.csv`)

По завершении проверки создается итоговый отчет `report.csv` следующего формата:
```csv
name,status,target,reserved,available_approx,details,notes
Nate Smith,OK,12,12,12,Успешно зарезервировано 12/12,
```

**Возможные статусы:**
* `OK` — Целевое количество билетов успешно зарезервировано.
* `ЧАСТИЧНО` — Зарезервирована часть билетов (например, 8/12 из-за лимита инвентаря).
* `НЕДОСТАТОЧНО` — Билеты недоступны для бронирования.
* `SOLD_OUT` — Билеты полностью распроданы.
* `ENDED` — Продажи на событие завершены.
* `BLOCKED` — Блокировка защиты DataDome (после исчерпания всех шагов восстановления).
* `ОШИБКА` — Ошибка навигации или недоступность страницы.
